What is Bro Gang AI CLI?

An open source agent that works in your terminal.

Bro Gang AI CLI helps you write code where you already are — in the shell. Give it a task and it reads your files, edits them, searches the tree and runs commands, reporting back what it changed.

It ships with a hosted, keyless model so the first command you type already works. Everything else is optional.

Usage
# interactive session
$ brogang

# one shot, print, exit
$ brogang "refactor the auth middleware"

# auto-approve every tool
$ brogang --yolo "fix the failing tests"

# fully local, no network
$ brogang -p ollama "explain this repo"

# see what's available
$ brogang --list-providers
Capabilities

Real tools. Real sandbox.

A genuine tool loop — not a chat box with a file picker bolted on.

Full agent loop

read_file, write_file, edit_file, list_dir, search and run_command, chained by the model across up to 24 rounds.

Sandboxed paths

Every file tool resolves against your workspace root and rejects .. escapes. Destructive shell commands ask before they run.

Zero configuration

The default provider needs no key and writes no config file. Setup is only for people who want to bring their own.

Any provider

Swap backends with -p. Eight built in, from the free hosted model to a local Ollama server.

Portable binary

Static Go build. No runtime, no node_modules, no virtualenv — it just runs.

Bang Mach theme

Neon pink and cyan built for long sessions, with spinners, box drawing and full NO_COLOR support.

Open endpoint

An OpenAI-compatible API. Free and keyless.

The CLI is just a client. Point anything at it — a script, a website, another agent. Same shape as the OpenAI SDK, so swapping the base URL is often all it takes.

  • 1POST /v1/chat/completions — chat, with optional tool definitions
  • 2GET /v1/models — list the available model
  • 3GET /v1 — endpoint metadata
curl
curl https://brogangaicli.pages.dev/v1/chat/completions \
  -H 'content-type: application/json' \
  -d '{
    "messages": [
      {"role":"user","content":"hi"}
    ]
  }'
